# Revisión de pulido · 0.2.0

Se integró GitHub 0.1.9 antes de aplicar los cambios locales pendientes. Se revisaron los módulos Python de reglas, circuito, partida, sesiones, medición remota y tutorial; el servidor local; y JavaScript/CSS de interfaz, cartas y esfera. Los módulos de arte contienen las imágenes aportadas por el autor.

Correcciones: manos visibles durante respuestas; Envido automático sin pantallas privadas obligatorias; resumen público después del resultado; privacidad opcional; validación de nombres, fichas y lotes de medición; bloqueo de cambios de contexto con mediciones pendientes; consultas al mismo job después de errores; mensajes y foco conservados en el editor; ayuda por turno, costos de cantos y explicación de bazas. Se corrigió además una carrera de interfaz que permitía marcarla libre mientras esperaba una respuesta.

La entrega agrega animaciones de cantos, tantos, puntos, medición y cartas al comenzar el turno. La original y la ligada tienen igual tamaño con nombres y porcentajes legibles. El mazo reduce X a una ficha y agrega todas las rotaciones fijas pedidas.

Ver `TESTING.md` para comandos reproducibles y `RELEASE_0.2.0.md` para alcance, decisiones y estado de publicación. El muestreo local no acredita nuevas ejecuciones IonQ.
